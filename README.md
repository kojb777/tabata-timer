# Tabata Timer — English Voice Edition

GitHub Pages対応のタバタ式Webタイマー（PWA）。画面は日本語、音声案内は英語です。

- デフォルト：運動20秒、休憩10秒、8ラウンド（最後の休憩なし）
- 3秒の開始前カウントダウン、運動・休憩の切り替え、ラウンド案内、終了音声
- 英語音声：ブラウザの英語音声から女性らしい名前の声を優先して選択（1.3倍速）。端末に該当音声がない場合は英語音声または既定音声にフォールバックします。女性音声を完全には保証できません。
- 電子音は初期状態でON。音声案内も初期状態でON。
- 開始・一時停止・再開・リセット、設定保存、オフラインキャッシュ

## GitHub Pagesへの公開
1. GitHubで `tabata-timer` などの公開リポジトリを作成。
2. ZIPを展開し、`index.html`、`sw.js`、`manifest.webmanifest`、アイコンをリポジトリの**ルート**にアップロードしてコミット。
3. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**。
4. `https://ユーザー名.github.io/tabata-timer/` にアクセス（リポジトリ名が異なる場合は変更）。
5. スマートフォンで開き、ホーム画面に追加できます。

## 音声に関する注意
音声はWeb Speech APIの端末内音声合成を利用します。端末やブラウザによって声の性別・音質・発声タイミングが異なります。開始ボタンを押して音声を有効化してください。iOS等では画面ロック中・バックグラウンドで音声が停止する場合があるため、画面を開いた状態で使用してください。ブラウザが音声合成を提供しない場合、電子音のみになります。
